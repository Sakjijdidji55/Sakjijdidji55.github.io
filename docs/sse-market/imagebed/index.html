06 图床：上传、鉴权与存储

4 分钟读完 · 1,611 字

图片托管服务：集市 OAuth 登录、三种上传入口、公开/私有可见性、个人 Token 与直链。Go + Gin + GORM，存储可切换本地目录或 MinIO。

仓库：github.com/SysuMirror/imagebed（server/ 约 2700 行 Go，web/ 前端）。

登录

① state 签名

  • 实现：state = 随机 nonce + HMAC-SHA256(nonce) 的前 16 个 hex 字符。回调时先校验长度与 hex 形态，再比签名，篡改或伪造都会被拒。
// server/service/oauth_service.go
func (s *OAuthService) sign(nonce string) string {
	secret := s.cfg.OAuth.AppSecret
	if secret == "" {
		secret = "imagebed-oauth-state"
	}
	mac := hmac.New(sha256.New, []byte(secret))
	mac.Write([]byte(nonce))
	return hex.EncodeToString(mac.Sum(nil))[:stateSigLen]
}

func (s *OAuthService) CreateState() (string, error) {
	nonce, err := util.RandomHex(stateNonceLen / 2) // 24 字节 = 48 hex 字符
	if err != nil {
		return "", err
	}
	return nonce + s.sign(nonce), nil
}

// ConsumeState 校验 state 的 hex 格式与 HMAC 签名，防篡改
func (s *OAuthService) ConsumeState(state string) bool {
	if len(state) != stateNonceLen+stateSigLen || !isHex(state) {
		return false
	}
	nonce := state[:stateNonceLen]
	...
}
  • 坑：secret 为空时退化为硬编码常量，等于没有签名。生产必须配 AppSecret，启动时应对空值直接报错。
  • 面试点：state 用「nonce + 截断签名」，URL 因此短一些；截断到 64 bit 仍足以抵抗伪造。

② 两步回调：access_token 不下发浏览器

  • 用户操作：点「集市账号登录」→ 授权 → 回到图床，已登录。
  • 实现：回调阶段用 code 换 access_token 后不返回前端，只在服务端内存里存一份（带 TTL），返回一次性 sessionId；前端用 sessionId 换本域 JWT。
// server/service/oauth_service.go
func (s *OAuthService) CreateCallbackSession(accessToken string) (string, error) {
	id, err := util.RandomHex(16) // 32 hex 字符
	if err != nil {
		return "", err
	}
	s.mu.Lock()
	s.sessions[id] = oauthSession{accessToken: accessToken, expiresAt: time.Now().Add(sessionTTL)}
	s.mu.Unlock()
	return id, nil
}

func (s *OAuthService) ConsumeCallbackSession(id string) (string, bool) { ... }

GET  /api/oauth/login-url   → { url }                 生成带 state 的授权地址
POST /api/oauth/callback    → { sessionId }           校验 state，用 code 换 token
POST /api/oauth/userinfo    → { token, user }          用 sessionId 取 userinfo 并签发本地 JWT
  • 坑：sessions 是进程内 map。多实例部署时，回调落在 A 实例、userinfo 打到 B 实例会取不到会话，需要换 Redis 或做会话粘性。
  • 坑：一次性会话必须「取出即删」，且过期时间要短（分钟级）。可重复使用就退化成长期令牌。

③ 换取本地身份

  • 实现：用 sessionId 取回 access_token，拉集市 userinfo，按 OAuthID upsert 本地用户，再签本地 JWT；GET /api/auth/me 返回当前用户。
// routes：oauth 组（无需登录）、auth 组（需 JWT）

上传

① 三种入口

  • 用户操作：网页拖拽/选择（可批量）；脚本用 multipart、原始二进制或 JSON base64。
  • 实现：三条入口最终都归一成 []byte 调 UploadService.Save，鉴权分别是 JWT（网页）与个人 Token（/api/upload）。
POST /api/auth/images           multipart/form-data   网页（JWT）
POST /api/upload                三种编码，Bearer Token 脚本
POST /api/auth/images           原始二进制 / base64   同一 handler 内分支

② 大小限制与类型嗅探

  • 实现：先判空、再判大小，然后内容嗅探（http.DetectContentType）比对白名单；SVG 单独放行（嗅探常返回 text/xml）；内容无法识别时才退回扩展名判定。
// server/service/upload_service.go
func (s *UploadService) Save(userID uint, originalName string, data []byte) (*model.Image, error) {
	if len(data) == 0 {
		return nil, errors.New("空文件")
	}
	if int64(len(data)) > s.cfg.MaxUploadBytes() {
		return nil, errors.New("文件超过大小限制")
	}

	ext := filepath.Ext(originalName)
	mime, err := util.ValidateImage(data, ext)
	if err != nil {
		return nil, err
	}
	ext = util.MimeToExt(mime)   // 落盘扩展名以嗅探结果为准

	subDir := time.Now().Format("2006/01/02")
	id := uuid.NewString()
	relPath := "images/" + subDir + "/" + id + ext
	if err := s.store.Put(ctx, relPath, bytes.NewReader(data), int64(len(data)), mime); err != nil {
		return nil, err
	}
	...
}

// server/util/imageutil.go
sniffed := http.DetectContentType(data)
if allowedImageTypes[sniffMime] {          // 嗅探命中白名单 → 以嗅探为准
	return sniffMime, nil
}
if ext == ".svg" && (sniffMime == "text/xml" || sniffMime == "image/svg+xml") {
	return "image/svg+xml", nil            // SVG 需结合扩展名放行
}
// 内容无法识别时，退回按扩展名判定
  • 坑：落盘扩展名必须用嗅探结果重写。保留用户传来的 .php，静态服务一旦按扩展名执行就是 RCE。
  • 坑：SVG 是 XML，可内嵌脚本。它按白名单被放行，就必须在响应头加 Content-Security-Policy 或强制下载，不能按图片直接渲染。
  • 面试点：先嗅探、再扩展名兜底，是因为部分格式（SVG、部分 BMP）没有稳定的 magic bytes；但兜底只能用于「无法识别」的分支，不能反过来。

③ 存储后端

  • 实现：blob.Store 接口抽象 Put/Get/Delete，实现有本地目录与 MinIO；对象键统一走 abs() 校验。
// server/blob/store.go
func (s *localStore) abs(key string) (string, error) {
	key = strings.TrimPrefix(filepath.ToSlash(key), "/")
	if key == "" || strings.Contains(key, "..") {
		return "", fmt.Errorf("非法对象键")
	}
	full := filepath.Join(s.root, filepath.FromSlash(key))
	if !strings.HasPrefix(filepath.Clean(full), filepath.Clean(s.root)) {
		return "", fmt.Errorf("路径越界")
	}
	return full, nil
}
  • 面试点：路径校验要做两次 —— 拒绝 ..，再比对清理后的前缀。只做前者，符号链接与编码绕过仍可能越界。

④ 元数据

  • 实现：落库记录 user_id、存储键、MIME、宽高、字节数、visibility、缩略图键；按日期分目录（YYYY/MM/DD），避免单目录文件过多。

② 可见性切换

  • 用户操作：图片卡片上切「公开 / 私有」。
  • 实现：只接受两个枚举值，非法值直接报错；先按 userID 找图，找不到即 404。
func (s *ImageService) UpdateVisibility(userID, id uint, visibility string) (*model.Image, error) {
	img, err := s.images.FindByID(userID, id)
	if err != nil {
		if errors.Is(err, gorm.ErrRecordNotFound) {
			return nil, ErrImageNotFound
		}
		return nil, err
	}
	if visibility != model.VisibilityPublic && visibility != model.VisibilityPrivate {
		return nil, errors.New("非法的可见性")
	}
	img.Visibility = visibility
	...
}
  • 坑：FindByID(userID, id) 必须带 userID 条件。用 id 单条件查再比 user_id，会先查出一条别人的记录再返回 403，等于确认了资源存在。

访问控制

① 直链服务

  • 用户操作：复制地址粘到任何地方即可显示；私有图只有本人带凭证能看。
  • 实现：/i/*filepath 统一处理 —— 校验路径、按路径找图、私有则解析用户、最后从存储读流返回。
// server/core/static.go
func serveImage(c *gin.Context, store blob.Store, imageSvc *service.ImageService,
	authSvc *service.AuthService, tokenSvc *service.TokenService) {
	rel := strings.TrimPrefix(c.Param("filepath"), "/")
	if rel == "" || strings.Contains(rel, "..") {
		c.AbortWithStatus(http.StatusNotFound)
		return
	}
	img, err := imageSvc.FindByPathForServe(rel)
	if err != nil {
		img, err = imageSvc.FindByThumbPathForServe(rel)
		if err != nil {
			c.AbortWithStatus(http.StatusNotFound)
			return
		}
	}
	if img.Visibility == model.VisibilityPrivate {
		uid, ok := resolveUser(c, authSvc, tokenSvc)
		if !ok || uid != img.UserID {
			c.AbortWithStatus(http.StatusNotFound)   // 越权一律 404，不暴露存在性
			return
		}
	}
	rc, err := store.Get(c.Request.Context(), rel)
	if err != nil {
		c.AbortWithStatus(http.StatusNotFound)
		return
	}
	defer rc.Close()
	...
}
  • 坑：私有图越权返回 404；403 等于告诉对方「这张图存在，只是不归你」。403 等于告诉对方「这张图存在，只是不归你」。
  • 面试点：鉴权放在「找到记录之后、读存储之前」。放在读存储之后会先产生一次对象读取，浪费带宽。

② 双凭证解析

  • 实现：优先读 Authorization: Bearer，其次读 ?token=（原生 <img> 带不了请求头），先按 JWT 解析，失败再按个人 Token 解析。
func resolveUser(c *gin.Context, authSvc *service.AuthService, tokenSvc *service.TokenService) (uint, bool) {
	raw := middleware.BearerToken(c)
	if raw == "" {
		raw = c.Query("token")
	}
	if raw == "" {
		return 0, false
	}
	if uid, err := authSvc.ParseToken(raw); err == nil {
		return uid, true
	}
	if t, err := tokenSvc.Authenticate(raw); err == nil {
		return t.UserID, true
	}
	return 0, false
}
  • 坑：?token= 会进浏览器历史、代理日志与 Referer。它只应作为 <img> 这类无法带头的场景的兜底，且令牌应短期、可吊销。

③ 路径穿越防护

  • 实现：serveImage 与 localStore.abs 双重校验：先拒 ..，再比对清理后的前缀。
rel 含 ".."            → 404
清理后不在 root 之下   → 404

② 认证

  • 实现：哈希后按哈希查记录 → 过期判断 → 更新 last_used_at → 返回 Token 所属用户。
func (s *TokenService) Authenticate(raw string) (*model.Token, error) {
	if raw == "" {
		return nil, ErrTokenNotFound
	}
	hash := util.SHA256Bytes([]byte(raw))
	t, err := s.tokens.FindByHash(hash)
	if err != nil {
		return nil, ErrTokenNotFound
	}
	if t.ExpiresAt != nil && t.ExpiresAt.Before(time.Now()) {
		return nil, ErrTokenExpired
	}
	_ = s.tokens.TouchLastUsed(t.ID, time.Now())
	return t, nil
}
  • 面试点：Token 用 SHA-256 而用户密码用 bcrypt，是因为 Token 是服务端生成的高熵随机串，不存在字典攻击面；用慢哈希只会让每次上传都多花几十毫秒。

图床 · 面试速答

  • 登录：state = nonce + 截断 HMAC；access_token 只留服务端，前端拿一次性 sessionId 换本域 JWT。
  • 上传：内容嗅探为准、扩展名兜底；落盘扩展名按嗅探结果重写；SVG 需额外 CSP。
  • 存储：blob.Store 抽象本地与 MinIO，对象键两次校验（拒 ..、比前缀）。
  • 权限：私有图越权返回 404；先鉴权后读存储。
  • Token：只存 SHA-256，创建时返回一次原文，认证时哈希查询并写 last_used_at。
  • 静态：SPA 回落需排除静态资源，避免把 404 变成语法错误。
