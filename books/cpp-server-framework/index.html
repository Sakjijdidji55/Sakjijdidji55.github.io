关于这本手册

c++Server（CBSF）是一个轻量级 C++ HTTP 服务框架，包含 HTTP 接入、路由与中间件、请求解析、响应构建、线程池、协程调度、MySQL / Redis 连接器以及 JWT 鉴权等模块。

这本手册把项目的设计拆成三层：

  1. 概览：先用一篇文章讲清整体架构与面试表达方式
  2. 模块设计：逐个模块说明职责、头文件接口与实现思路
  3. 函数级手册：细到每个公开函数的参数、返回值和边界情况

使用方式

  • 第一次接触项目：从「架构与面试讲解」开始
  • 想改某个模块：直接跳到对应的模块设计章节
  • 查函数签名：翻到最后的函数级手册
